## 发现的问题
- **测试夹具不能假设自增 id = 1**：SQLite 的 AUTOINCREMENT 序列跨用例不回落，`categoryId: 1` 硬编码在第二次运行时 404。改成 beforeEach 捕获真实 id
- **纯函数抽出来前后测试写法的差异**（任务卡检查题的回答）：抽出前，测一个"单位不存在"要起整个 Nest 应用、seed 5 个角色、登录拿 token、造 xlsx 上传——一个用例约 700ms，且文件级错误（非 xlsx）和行级错误混在一起只能全走 e2e；抽出后，行级校验用例变成纯内存调用（<1ms/个），可以直接断言错误消息的具体文案、批量断言组合错误，e2e 只留文件级（魔数、解析失败）和链路级（库写入、响应结构）的用例。代价是 Service 与校验函数之间多了一层"查参照数据→传 Set"的胶水，但测试速度和覆盖密度收益明显更大。
