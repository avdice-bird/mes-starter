## 时区处理方式（任务卡要求写明）

**UTC 毫秒 + 固定偏移表**：`factoryLocal(at) = new Date(at.getTime() + 8h)` 后取 getUTCHours/Minutes。三优点：不依赖服务器 TZ（投屏把系统时区改 UTC 结果不变）；无 dayjs 依赖；纯函数好测。局限：不含夏令时（中国无 DST，本项目够用），多国工厂再换 dayjs.tz。

## 磨课过程抓的两个坑（都在"参数传递"上）

1. **supertest query 里 `+` 被解析成空格**：`?at=...+08:00` 到服务端变成 `... 08:00` → "不是有效 ISO"。双修：测试用 `%2B` 编码；服务端容错把 `HH MM:SS` 还原成 `HH+MM:SS`。这类 bug 报错信息完全不指向根因，靠分段打印响应才定位。
2. **"晚班 00:00-08:00"的 crossDay 语义**：数值上 0→480 不需要拆段（`m ∈ [0,480)` 直接命中 00:30），crossDay 公式 `end ≤ start` 对它返回 false 是**数值事实**；真正的跨天是 22:00-06:00（360≤1320）。current 判定对两种都正确——第一次写测试时我把两个概念搅在一起，画时间轴才理清。
