# 前端细节清单

磨节课用。复制到 `docs/checklists/<模块>-前端.md`，逐项打勾。

## 状态反馈
- [ ] 列表加载有 loading
- [ ] 列表无数据有空状态提示（不是空白表格）
- [ ] 请求失败有错误提示（不是白屏、无反应、console 报错）
- [ ] 提交按钮在请求中禁用，防重复点击
- [ ] 操作成功有提示，列表自动刷新

## 表单
- [ ] 校验规则与后端 DTO 一致（必填 / 长度 / 格式 / 范围）
- [ ] 后端返回的校验错误能显示出来（至少 message，最好到字段）
- [ ] 编辑时回填完整；关闭弹窗后表单重置，不残留上一条数据
- [ ] 下拉数据（分类、单位、字典）来自接口，不写死
- [ ] 危险操作（删除、下达、关闭、取消）有二次确认

## 表格
- [ ] 分页、排序、筛选可用，参数与后端一致
- [ ] 时间 / 枚举 / 状态 / 数量有格式化显示（状态用 tag 带颜色）
- [ ] 列宽合理，长文本不撑破布局
- [ ] 搜索框回车触发搜索，有重置按钮

## 权限
- [ ] 无权限的按钮不显示（`v-permission`）
- [ ] 无权限的路由跳 403 页
- [ ] token 过期自动刷新；刷新失败跳登录并保留回跳地址
- [ ] 按状态显隐操作按钮（例如已完工的工单没有"开工"按钮）

## 体验与健壮性
- [ ] 关键页面 console 无报错、无警告
- [ ] 刷新页面不丢登录态、不丢当前路由
- [ ] 弹窗、抽屉可以用 Esc 关闭
- [ ] 移动端/窄屏至少不错位（报工页、看板页需要）
