  2. Material 加两个反向关系（`parentBoms`/`childItems`，命名关系避免歧义）。
- migration 用 `prisma migrate diff` 生成（交互式 `migrate dev` 在非 TTY 环境不可用，这是第二次遇到——记入坑）。
