- **getCurrentShift 的时区设计（本节核心判断）**：`factoryLocal()` 用 UTC 毫秒 + 固定时区偏移表（Asia/Shanghai=+8）换算本地时分，**不用 `new Date().getHours()`**——后者取决于服务器时区，容器里 TZ=UTC 时全错。偏移表覆盖常见工厂时区，FACTORY_TZ 可配。
- `getCurrentShift(at)` 把时间作为**参数**：测试传固定 ISO 即可覆盖所有分支，不需要 mock 时钟（这也是第 25 节的检查问题——答案：可测性 + 同一函数可服务"查任意时刻的班次"如补卡/追溯）。
