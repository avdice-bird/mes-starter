# 第 17 节 · BOM · 【磨】展开算法

- 日期：2026-09-22
- 目标：循环、深度、汇总、损耗、日期版本五个坑全处理
- 用时：课内 40 分钟 / 课外约 90 分钟

## 两个决策（任务卡要求写明）

1. **损耗率口径**：实际需求 = 用量 × (1 + 损耗率/10000)（**乘法口径**）。理由：损耗是"额外多备"的余量，语义是"多买 3%"而不是"打 97 折"；且 100% 损耗在乘法口径下 = 双倍（合理），除法口径会除零。损耗在**每层应用后立即四舍五入**（与逐层 MRP 一致），不是最后统一取整——这个口径差异让我的第一版手算期望值错了（详见日志 18）。
2. **激活策略**：激活 v2 时同父物料的其他 ACTIVE **自动置 OBSOLETE**（而不是拒绝）。理由：业务上"切换生效版本"是主动管理动作，让操作员先去手动废弃旧版是纯粹的摩擦；同事务 updateMany 保证任何时刻只有一个 ACTIVE。

## 发现的问题

- 保存明细时的环检测初版只查"子件是否指向自己"，跨 BOM 环（A→B→A）漏掉——改为保存后用内存图做可达性检测（`assertNoCycle`），与展开共用图结构，行为一致。
