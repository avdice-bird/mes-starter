## 模板 v2 反哺（8 条 `<!-- v2 -->` 规则，超过任务卡 5 条的下限）

1. **不可变字段清单**作为模板输入项：Update DTO 不得出现、前端 disabled、创建弹窗提示（对应 code 不可改）；
2. **下拉提供方**作为输入项：需要时生成"按业务标识取启用项"只读接口 + 扫描白名单登记；
3. 唯一冲突 Service 捕获 P2002 转业务化消息（不用过滤器通用文案）+ 写清唯一范围；
4. 有关联子项的删除：先查子项数，409 + 具体项数，e2e 必测；
5. sortBy 白名单防任意字段排序；
6. status 语义：下拉/选项类查询只返回启用项；
7. 主从结构用 el-drawer 而非二级页面；
8. 提供下拉时必须有组合式函数（模块级缓存 + invalidate + Vitest 三例）+ 自检段加"带参路由也要进矩阵行""invalidate 调用点在维护成功的路径里"。
