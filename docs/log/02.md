## 发现的问题

- **追问点（读不懂后追问 AI）**：refresh token 为什么用随机串入库而不是也用 JWT？——因为 JWT 无状态、无法主动吊销；随机串每次校验查库，才能做到登出失效、轮换作废、重放拒绝。理解后保留了这个设计。
