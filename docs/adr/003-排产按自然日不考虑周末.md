# ADR-003：排产按自然日、不考虑周末

- 日期：2026-10-09
- 状态：已采纳
- 关联节次：第 26、27 节（用例 13）

## 背景

排产以"日"为粒度把工单填进产线日历。真实工厂周末不开工（或开半班），如果排产算法把周末当正常产能日，计划的 plannedEnd 会偏乐观。但小型电子装配厂也可能周末加班，是否考虑周末是业务配置，不是纯技术问题。

## 候选方案

1. 方案 A：现在就做工作日历（每产线一张周历 + 节假日表）——精确，但要多两张表和一个维护界面，超出本节范围。
2. 方案 B：排产完全按自然日（周一到周日都算产能日）——简单、可预期，周末不开工的工厂排出的计划偏乐观。
3. 方案 C（AI 建议）：引入 `SystemSetting` 开关 `schedule_skip_weekend`，算法里跳过周六周日。

## 决定

选方案 B，把"周末"登记为扩展点：算法里的日期推进只走 `addDays`，日历语义集中在 `firstFreeRun` 的"该日是否可用"判断上。将来接入工作日历时：

1. 给 `SchedulableWorkCenter` 加 `workingDays`（或产能按星期几的数组，周末记 0）；
2. `firstFreeRun` 的空闲判定从"占用为 0"改为"占用 < 当日产能"；
3. 输入不变，单测里补一个"周六不排"用例即可。

## 后果

- 现在的实现可预期、好手算（第 28 节测试要求期望值能纸上复算）；
- 周末不开工的工厂会用排产结果偏乐观，这是已知限制（验收标准里写明）；
- 扩展点收敛在一个函数，改动不波及排序、延误判定和写库逻辑。
