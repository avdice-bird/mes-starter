## 我做了 / 复算抓到的问题

1. **cancel 400 假象**：Controller 返回 `{ code: 1001 }` 裸对象被响应拦截器包成 code=0 成功——HTTP 201。修正为 `throw new BadRequestException`（同时把 work-orders findOne 的 404 裸对象一并修掉）。教训：统一响应架构下"返回错误码对象"永远是坑，要么抛异常要么抛 BusinessException。
2. **权限矩阵的状态演进**：release 行真实执行后工单变 RELEASED，后续 start/pause/resume 的期望必须跟着状态走（201）而不是想当然的 409；夹具改用**独立物料**挂 ACTIVE 路线，否则破坏旧的"MX-RT 无路线 → 404"行。
3. 业务字典（work_order_status）不在 RBAC 种子里——resetDb 清掉 Dict 后测试自灌 `seedDicts()`。
