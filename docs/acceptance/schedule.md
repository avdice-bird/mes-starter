排产口径（ADR-003）：

- 产线日产能 = `WorkCenter.dailyCapacity`；工单天数 = ceil(qty / 日产能)
- 同产线顺序排：整日占用，不做日内混线；已占用日产能视为满，顺延下一日
- 按自然日排，不考虑周末（扩展点：周末产能记 0 即可接入）
- 时间口径：计划起止为 UTC 日历日（00:00Z），前端展示年月日
