## 修复要点

- JWT secret 硬编码兜底 → `common/config/env.ts` 强制环境变量，缺失启动即失败（这也是之前 e2e 挂掉的根本原因）。
- 单测发现 mock 用户缺 `failedAttempts` 字段导致断言 `NaN` —— 修测试夹具而非放宽断言。
- 登录"清零计数 + 签发 refresh"、刷新"作废旧 + 签发新"收进 `$transaction`，防中途失败留下脏状态。
