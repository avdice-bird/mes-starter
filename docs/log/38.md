## 超产策略与并发实现方式（任务卡要求写明）

- **超产策略（用例 3）**：选择**拒绝超产**（2002），容差 0%。理由：本课数据里 plannedQty 就是下达快照，允许超产会让"下道 ≤ 上道良品"的不变量需要额外解释；容差常量 `OVERPRODUCTION_RATE_PCT` 收敛在一个文件顶部，将来挪到字典 `overproduction_rate` 只改一处。
- **并发实现（用例 2）**：**原子累加**（`{ completedQty: { increment } }`）而不是乐观锁读-改-写。理由：累加操作天然可交换，increment 由数据库原子完成，不存在 ABA；乐观锁留给"状态流转"（transition）这类必须以旧值为前提的操作。超量校验基于事务内刚读的任务行 + SQLite 写串行，无 TOCTOU 窗口。
