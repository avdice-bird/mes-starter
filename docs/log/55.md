## 踩坑

1. **第 54 节埋的迁移时间戳错序**：`20261010150000_report_indexes` 排在建 `WorkReport` 表的 `20261011000000` 之前——dev 库当时直接 deploy 成功（已存在的表），但从零部署（CI/shadow）会在索引迁移处炸 `no such table: main.WorkReport`。修：目录改名到 `20261011500000`、SQL 改 `CREATE INDEX IF NOT EXISTS`、dev 的 `_prisma_migrations` 记录同步替换。**教训：迁移文件名的时间戳必须真的按依赖排序，不能想当然"今天建的就用今天"**。
2. **multipart 中文文件名乱码**：busboy 按 latin1 解析文件名，`中文 SOP 手册.pdf` 回包变 mojibake——上传时 latin1→utf8 还原。
3. API 冒烟时附件随手挂 `refId=1`，浏览器验证报工页 SOP 按钮不出现——链路是 `routingId + operationCode → RoutingOperation.id(255)`，refId 必须是真实路线工序 id。**集成点要用真实链路造数，别用"顺手"的 id**。
