# 排产甘特图验收标准（第 29 节）

| # | 验收项 | 验证方式 | 结果 |
|---|---|---|---|
| 1 | 显示：按产线分行、日期分列（默认今天起 14 天，可前后翻周） | 打开"排产甘特图"页，已排工单按产线显示为条 | ✅ |
| 2 | 条的颜色语义：CREATED 蓝、非 CREATED 灰（不可拖）、延误红边 | 造一张 RELEASED 工单与一张延误工单对照 | ✅ |
| 3 | 水平拖动改日期（保持时长），松手 `PATCH /work-orders/:id/plan` 回写 | 拖动后刷新页面，计划日期仍在（持久化） | ✅ |
| 4 | 跨行拖动改 workCenterId | 拖到另一产线行，刷新后产线已变更 | ✅ |
| 5 | 拖拽失败回滚：接口报错时 ElMessage 提示并 reload（服务端旧值为准） | 临时断开后端拖动 → 提示"计划未保存"，数据不变 | ✅ |
| 6 | 冲突提示：同产线同日均摊量 > 日产能 ×1.3 → 该日期列黄底 | 同产线堆两张大工单，日期列变黄 | ✅ |
| 7 | 仅 CREATED 可拖；其他状态拖动被拦截（条不可拖 + drop 时校验） | 拖 RELEASED 条不响应/提示 | ✅ |
| 8 | 权限：`schedule:adjust` 控制 plan 接口；页面查看只需 `work-order:view` | operator 拖动 → 403（前端 hidden 由 v-permission 管按钮，接口为防线） | ✅ |
| 9 | 后端校验：end ≥ start、产线存在且启用、非 CREATED 拒绝（1006） | e2e 用例覆盖（schedule.e2e-spec.ts） | ✅ |

口径说明：冲突计算用"工单数量按天数均摊到日"的简化口径（本课无分时段产能明细），超产能 30% 容差才标黄，避免排产算法贴产能上限时误报。

遗留（任务卡提示的课外项，详见 log/29.md）：拖到过去日期、拖出可视范围、同格重叠条的显示。
