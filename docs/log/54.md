## 踩坑

1. **M4 fixture 与压测数据互污**：1 万条压测流水落在对账日 → 早班良率 2660/30 而非 80/15。报表没错，是"干净基线"没了——对账/M4 必须在清表+种子+fixture 的库上跑，压测放最后。
2. **`c.base` 含 `/api`**：verify 框架的 base 是 `http://localhost:3000/api`，拼 socket 命名空间成了 `ws://.../api/board`——静默连不上。M4 的 WS 检查改为剥掉 `/api` 再拼。
3. **`@Query()` 裸参数不自动转换**：`/employees?teamId=16` 500（Prisma 收到字符串）——controller/service 两处补 `Number()`。顺带清掉了 Windows 上又一个 `nest --watch` 双实例残留（这次直接 `nest build && node dist/src/main.js` 跑单进程验证）。
4. 全量回归：单测 153/153、e2e 379/379、Playwright 5/5（限流窗口内偶发重试 1 次通过）、tsc 干净；lint 剩 11 条均为本节之前的历史遗留（stash 对照确认）。
