- [x] 编辑回填完整；弹窗 destroy-on-close 不残留
- [x] 下拉数据来自接口：字典项状态开关为固定枚举（0/1），N/A 接口下拉
- [x] 危险操作二次确认：删除字典/字典项均 ElMessageBox.confirm
- <!-- v2 --> 不可修改的业务标识字段（code）：编辑弹窗 disabled + 创建弹窗下方提示"创建后不可修改"——用户不用等 404/409 才知道规则

- [x] console 无报错（浏览器实测全流程）

- [x] 抽屉/弹窗 Esc 可关（Element Plus 原生）
